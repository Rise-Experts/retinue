List of HTTP status codes

This is a list of Hypertext Transfer Protocol response status codes. Status codes are issued by a server in response to a client's request.[1]

4xx client errors

CodeReason phraseRetryable
403ForbiddenNo
404Not FoundNo
429Too Many RequestsYes — honour Retry-After
451Unavailable For Legal Reasons

Notes

  1. The 4xx class is intended for cases in which the client seems to have erred.
  2. Codes in the 5xx range indicate a server error.
    • 500 is the generic case.
    • 503 usually carries Retry-After.
