Array.prototype.flatMap()

The flatMap() method returns a new array formed by applying a given callback function to each element, and then flattening the result by one level. See also flat().

Syntax

flatMap(callbackFn)
flatMap(callbackFn, thisArg)

Parameters

callbackFn
A function to execute for each element. Its return value is added to the new array, flattened.
thisArg (optional)
A value to use as this when executing callbackFn.
