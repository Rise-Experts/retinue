# Brand marks

Built on the identity that already existed rather than a new one: **#234b7e** navy (the site's light-mode
primary, and the "SNIPE Navy" the document skills already use), **#4f81bd** blue as the accent, **#7aa6d8** for
dark backgrounds.

| File | What it is |
|---|---|
| `rise-experts-mark.svg` | The organisation's mark, icon only |
| `rise-experts-lockup.svg` | Mark plus wordmark, for a site header or a letterhead |
| `retinue-mark.svg` | Candidate product mark — a principal and its retinue |
| `retinue-lockup.svg` | The same with the wordmark, so the name can be judged *as* a logo |
| `steward-mark.svg` | Alternative candidate — custody rather than control |
| `steward-lockup.svg` | As above |

## One thing that is not production-ready

The wordmarks use `<text>` with a font stack, not outlined paths. That means they render with whatever font the
viewer has, so the letter shapes are **not fixed** — the same file can look different on two machines, and a logo
whose shapes move is not a logo.

It is deliberate at this stage: the name is not decided, and outlining type is the last step, not the first.
Before any of these is used publicly, the chosen wordmark needs its type converted to paths against a licensed
face. The marks themselves are geometry and are final.
